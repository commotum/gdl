# 6-INTEGRATE

## Result

- The ordinary `uv run scripts/archive-x --user USERNAME` path creates and
  finalizes telemetry without new required flags.
- Modern, legacy, shared-media, context-seed, context-metadata, context-media,
  and export transitions are represented.
- Routine context pacing lines collapse into current activity when telemetry is
  active; raw gallery-dl events and durable run logs remain available.
- Non-tmux runs receive slow plain-text heartbeats. README documents tmux,
  standalone inspection, opt-out, metric semantics, and ETA limitations.
- Existing exit codes, locks, phase order, pacing, and interruption paths are
  unchanged.
